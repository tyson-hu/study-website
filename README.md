# Networking Study Platform

**Independent Project · Began during U.S. Army AIT**

Networking Study Platform is an independent networking study application I
began as a personal tool during U.S. Army AIT and later shared informally with
peers preparing for networking-related course tests. It brings reference
material, immediate-feedback Practice, and timed test-style preparation into
one responsive interface.

## Live Application

[study.tianzhe.me](https://study.tianzhe.me)

## Why I Built It

I wanted one faster interface for moving between networking study material,
practice questions, and timed preparation instead of relying on disconnected
resources. The project began as a personal study tool and was later used
informally by peers preparing for networking-related course tests.

## Features

- Two bundled sets: Networking Essentials (205 questions) and Network
  Fundamentals (199 questions)
- Practice mode with immediate feedback and explanations where available
- Test mode with a randomized 50-question selection and a two-hour timer
- Four answer formats: single choice, multiple choice, typed response, and
  matching
- Results review, including unanswered-question handling
- Browser-local progress persistence across refreshes
- Keyboard controls for answering, navigation, checking, and submission
- External study notes for both quiz sets
- Army Net reference for generic switch, router, DNS, DHCP, and directory
  services lab concepts
- Responsive light and dark interfaces

The application has no accounts, backend, API, or database. Question data and
available explanations are bundled as versioned JSON.

## Architecture and Stack

- Next.js 16 with the App Router
- React 19 and TypeScript
- Tailwind CSS 4
- Base UI primitives, Motion, next-themes, Lucide, React Markdown, and Sonner
- Static export generated by `next build`
- Cloudflare Pages hosting

The dynamic quiz route uses `generateStaticParams` to emit every supported set
and mode during the build. Interactive state runs in the browser and progress
is stored in `localStorage`, with an in-memory compatibility mode when browser
storage is unavailable.

## Deployment

`next.config.ts` sets `output: "export"`, so `npm run build` writes the complete
site to `out/`. Cloudflare Pages serves that static output at
[`study.tianzhe.me`](https://study.tianzhe.me). The repository's Wrangler
configuration points Pages at the same `out/` directory.

`npm start` previews an existing export locally with Cloudflare's Pages
development server; run `npm run build` first. `npm run pages:deploy` is the
manual direct-upload command for authorized maintainers. The live project is
not deployed on Vercel.

## Usage Evidence

For the 30 days ending August 17, 2026, hostname-filtered Cloudflare Web
Analytics estimated approximately **1,800 visits** and **4,000 page views**
after excluding traffic Cloudflare classified as bots. The underlying estimates
were 1,810 visits and 3,960 page views for `study.tianzhe.me` with `bot=0`.

Visits are not equivalent to unique people, students, or verified users.

## Local Development

Requirements: a current Node.js LTS release and npm.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To build and preview the Cloudflare Pages static export:

```bash
npm run build
npm start
```

The Pages preview is available at
[http://localhost:8788](http://localhost:8788) by default.

## Validation

Run the same validation used by CI:

```bash
npm run validate
```

That command runs ESLint, standalone Next.js/TypeScript validation, focused
quiz-logic tests, the question-set integrity check, and the production static
export. Pull requests and pushes to `main` run the same sequence in GitHub
Actions.
